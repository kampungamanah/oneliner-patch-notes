# oneliner-patch-notes

A software patch note for a bug in real life.

`main.ts` writes the line to `/output/entry.txt`:

> v2.0.1: Fixed a memory leak where names vanished the moment introductions ended.

## Run

    node main.ts

It writes the entry text to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, else `/output/entry.txt`.
